# Mana HUD

Consulte o README antes de instalar ou abrir a interface. Execute `ai-usagebar usage` para obter métricas atuais. Não invente limites ou horários e não registre credenciais. HP e MP representam janelas distintas fornecidas pelos serviços. A janela Codex funciona somente no Windows; o painel Claude é experimental e o macOS ainda não foi validado.
